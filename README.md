## 📂 Featured Projects

### 🛡️ FraudGuard — Financial Fraud Detection

A financial fraud detection system that uses a trained machine learning model to identify potentially fraudulent transactions.

Built the Flask backend and prediction API, implemented data preprocessing, feature engineering, and missing-value handling, and analyzed transaction patterns based on frequency, amount, mode, location, and time.

**Technologies:** Python, Flask, Pandas, Scikit-learn, Joblib/Pickle

---

### 🩺 HealthBuddy — AI Medical Report Summarizer

An AI-powered application designed to simplify medical reports by extracting and summarizing important information.

The project focuses on processing medical reports and presenting relevant information through a user-friendly interface.

**Technologies:** Python, Streamlit, AI/ML, OCR, Gemini

---

### 🤝 VolunteerHub

A full-stack volunteer and community platform designed to connect users with volunteering opportunities and community activities.

The application includes user authentication, volunteer opportunities, categories, and an admin dashboard for managing platform data.

**Technologies:** React.js, Node.js, Express.js, MongoDB, MongoDB Atlas, JWT

---

### 🇮🇳 BharatVirasat

A heritage and artisan platform focused on discovering Indian heritage sites, artisans, and cultural products.

The project combines a modern web interface with backend APIs and database-driven content.

**Technologies:** React.js, Node.js, Express.js, MongoDB, Mongoose

---

### 📚 Library Management System

A web-based library management application for managing books, members, and library operations.

The project provides an organized interface for handling library records and common book management operations.

**Technologies:** Flask, SQLAlchemy, SQLite, React.js

---

### 🗂️ File System UI

A frontend interface that recreates a file-system-like experience for browsing, organizing, and managing files and folders.

The application focuses on creating a clean and responsive file management experience.

**Technologies:** React.js, Vite, Tailwind CSS

### 🕌 Zakat Calculator

A responsive web-based Zakat Calculator designed to make Zakat estimation simple and convenient.

Users can enter eligible wealth and asset values to calculate the estimated Zakat amount instantly. The application uses a 2.5% calculation rate and provides a clean, user-friendly interface.

**Technologies:** HTML5, CSS3, JavaScript

🔗 **[Live Demo](https://saifur-rahman123.github.io/zakat-calculator/)**

### 📺 Peblo miniTV

A full-stack streaming platform with a CMS and Netflix-style viewer for managing and browsing shows and episodes.

The system includes catalog publishing, role-based access, validation, and automated testing.

**Technologies:** FastAPI, PostgreSQL, SQLAlchemy, React, TypeScript, Vite, Docker

---

### ⚙️ eSIM Tool Manager

A Python-based automation tool for managing external dependencies used by eSim, including tools such as Ngspice and KiCad.

The application automates tool installation through OS package managers, performs dependency checks, verifies installed versions, and provides a command-line interface for tool management.

**Technologies:** Python, CLI, Automation, Unit Testing
